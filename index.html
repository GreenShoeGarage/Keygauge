To photograph your key

  1. Place the key on a flat, contrasting surface.
  2. Place a ruler, reference card, or calibration marker beside it.
  3. Keep the key and reference object in the same flat plane.
  4. Position the camera directly above the key.
  5. Make sure the complete blade, shoulder, and tip are visible.
  6. Avoid shadows, glare, blur, and angled photographs.

GUIDE, LIMITATIONS & PRIVACY

Use KEYGAUGE responsibly

Batch 9 changelogDownload README

Screen method

Calibrate in full screen at 100% browser zoom, select a verified profile, align the shoulder or tip, and adjust each cut. A browser cannot infer true physical size from resolution alone.

Photo method

Keep the scale reference in the same plane as the key. Correct perspective, then verify the baseline, reference, and every cut. Unscaled photos remain explicitly uncalibrated.

Private by design

Processing, autosave, profiles, and records remain in this browser. There is no telemetry, analytics, advertising, remote image analysis, or account.

Professional verification

KEYGAUGE is a visual measurement and documentation aid. Wear, parallax, display calibration, image blur, and unverified profile data can all affect estimates.
